# Focus XII — CBSE Class 12 PCM Study Planner

This PWA contains **266 individual topic tasks** across 37 CBSE Class 12 chapters:
- Physics: 14 chapters
- Chemistry: 10 chapters
- Mathematics: 13 chapters

## Use
Open `index.html` in a browser. Data is saved in that browser's local storage.

## Daily schedule
The app schedules topics sequentially from the selected start date. Default is 3 tasks/day; change to 2, 4, 5 or 6. The app shows the tasks assigned to the current date and a backlog of earlier unfinished topics. Change the start date to restart/re-plan the task calendar; checked progress remains saved.

## Streaks
A date counts as a study day when at least one syllabus task is checked on that date. Current streak is calculated automatically from consecutive active dates. If you miss a day, the streak pauses/resets based on consecutive days.

## Install on Android / iPhone
For install and offline support, host the folder on HTTPS (e.g. GitHub Pages or Netlify), then open it on your phone and choose Install app / Add to Home Screen.

## Curriculum source
Built around CBSE Academic Curriculum 2026–27:
- Physics: https://cbseacademic.nic.in/web_material/CurriculumMain27/SecPart2/Physics_SecP2_2026-27.pdf
- Chemistry: https://cbseacademic.nic.in/web_material/CurriculumMain27/SecPart2/Chemistry_SecP2_2026-27.pdf
- Mathematics: https://cbseacademic.nic.in/web_material/CurriculumMain27/SecPart2/Maths_SecP2_2026-27.pdf

Note: This tracker converts the published assessed theory syllabus topics into actionable study tasks. CBSE separately lists some Chemistry enrichment areas as formative-only; these are not included in the assessed board-theory task count. Follow the latest CBSE document and your school/teacher for any subsequent updates or prescribed exclusions. It is a study planner, not a substitute for the official syllabus.
